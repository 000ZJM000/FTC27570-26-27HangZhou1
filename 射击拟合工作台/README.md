# 06 射击拟合工作台

双击 `index.html` 即可离线打开。初始样本有 35 条记录，其中 22 个实测点参与拟合。已有新版角点的格子会屏蔽旧版精测。

- 点击场地查询任意右、前坐标，或点击实测点查看残差、改角度和转速、调权重。权重设为 0 可将该点排除。纵向剖面随查询位置的右坐标变化。
- 射向由反解的等效得分点与标准化多项式残差组成，转速拟合为到该点距离的一维函数。计算从车端导出的云台转轴位置进行。右半场按中线镜像，机械角度微调在镜像之后叠加。
- 误差栏和留一验证使用点权重计算均方根误差。虚线和浅色箭头表示测点包络之外的外推。
- 导入 Control Hub 上的 `/sdcard/FIRST/biobuzz/shot_records.json`。保存方案导出 `shot_model.json`，放回同一目录后重新 INIT 角落模式即可加载。下载 CSV 可查看逐点实测值、预测值和残差。
