# 06 射击拟合工作台

双击 `index.html` 即可在浏览器离线打开。初始数据来自两张 07 截图，共 35 条记录，其中 23 个实测值参与拟合，12 个不可达格保留在记录和地图中。格心、四角坐标沿用 06 的车身尺寸，旧精测点沿用截图坐标。

- 点击场地查询任意右、前坐标，或点击实测点查看残差、改角度和转速、调权重。权重设为 0 可将该点排除。纵向剖面随查询位置的右坐标变化。
- 射向由一个按实测反解出的等效瞄准点，加上可选的多项式修正组成。转速独立用多项式拟合。正则化越强，非恒定项受到的约束越大。右半场预览按中线镜像，右半场新增实测会按相同约定换算到基准坐标。
- 误差栏使用均方根误差。留一验证每次取出一个实测点，重新拟合后预测该点。虚线和浅色箭头表示测点包络之外的外推。
- 可粘贴 07 的点位文字补充测点，也可导入先前保存的 JSON。保存方案会导出数据、方程、系数和拟合参数，下载 CSV 会导出各点的实测值、预测值和残差。
