# 06 射击拟合工作台

双击 `index.html` 即可离线打开。初始样本有 35 条记录，其中 22 个实测点参与拟合。已有新版角点的格子会屏蔽旧版精测。

- 点击场地查询任意右、前坐标，或点击实测点查看残差、改角度和转速、调权重。权重设为 0 可将该点排除。纵向剖面随查询位置的右坐标变化。
- 射向默认先用 Huber IRLS 联合反解等效得分点 `(gx, gy)` 与整体零位偏置 `goalOffsetDeg`（可选叠加标准化 `(u, v)` 多项式残差），转速拟合为到目标的距离 `r` 的多项式加上有界方向谐波修正 `a_c cos β + a_s sin β`（8 点及以上自动启用）。支持 **抗离群点拟合 (Huber)**、**方向 RPM 修正** 开关，以及基于留一交叉验证自动网格搜索的 **自动寻优**。计算从车端导出的云台转轴位置进行。右半场按中线镜像，机械角度微调 `angleTrim` 在镜像之后叠加。
- 误差栏和留一验证同时给出加权均方根误差与绝对残差中位数。虚线和浅色箭头表示测点包络之外的外推。
- 导入 Control Hub 上的 `/sdcard/FIRST/biobuzz/shot_records.json`。06 START 后自动导出，按 L3 切到数据查看后按 Y 可重导。保存方案导出 `shot_model.json`，放回同一目录后重新 INIT 手动或 Pedro 自动即可加载。下载 CSV 可查看逐点实测值、预测值和残差。

车端优先读取有效的本机模型，其次读取 APK 内置模型，再尝试 06 测点拟合。仓库中的 `测点/shot_model.json` 会随构建打包为内置模型，替换它后重新构建并安装 APK。

## 新角度少点迁移

调整发射器固定俯仰角后，使用少量新实测锚点，估算既有格心和精测点的射向、RPM。界面入口为 **新角度少点校准**。

1. 导入原先的完整测点或方案，打开迁移窗口，点击 **将当前表设为基准**。
2. 在车上重测锚点。常用选择为覆盖近远距离的 6 个格心 `110`–`610`。
3. 在窗口粘贴 06 数据查看中的点位文字并点 **填入锚点表**，或通过 **读取 JSON/TXT** 读入新实测。核对自动选中的锚点，可直接修改新射向与 RPM。**提取格心锚点** 可快速勾选格心。
4. 选择算法、射向处理和 RPM 径向阶数。预览表显示每个点的旧值、新值、迁移量和计算方式，摘要给出实际锚点数、更新点数及近远端偏移。
5. 点击 **应用校准到全部精测点** 更新主表，再点击主页面 **保存方案**。将导出的 `shot_model.json` 复制回 Hub，下次 INIT 角落模式时加载。

| 迁移算法 | 计算方式 |
| --- | --- |
| 贝叶斯 MAP 2D 几何 + 抗噪收缩（推荐） | 相对平滑旧模型计算偏差，联合 2D 几何 MAP 拟合目标/零位微调与 Huber 径向 RPM 曲线，自动降权单点跳变并对锚点/非锚点做经验贝叶斯收缩融合 |
| 格心抗噪锚定 + 径向梯度迁移 | 基于平滑基准叠加抗噪限幅后的同格微差与径向梯度 |
| 全局平滑曲线迁移 | 对基准记录统一应用 2D 几何与稳健径向 RPM 偏移 |
| 新角度曲线 + 旧残差 | 拟合新锚点曲线，再叠加原测点相对旧曲线的局部残差 |

射向默认优先采用 **2D 几何 MAP 拟合**（可切换统一零位平移，或保持原射向仅校准 RPM）。RPM 径向阶数可选常数、一次或二次，锚点较少、射程跨度不足或存在单点跳变时会自动降阶并使用 Huber 抗噪拟合，预览摘要及表格会提示被自动降权的离群锚点。

## 基准与文件

**还原到 24 点基准** 将主表恢复为当前保存的基准。当前表可以重新设为下一轮迁移的基准，实际记录数量由已加载的数据决定。

普通导入窗口的 **作为新角度少点锚点** 选项，会按当前迁移设置直接应用导入数据。需要逐点查看迁移结果时，可使用独立的迁移窗口。

`shot_model.json` 保存当前测点、`baselinePoints`、机械尺寸、拟合参数和模型。再次导入该方案可以继续使用原基准。迁移结果中的估算点可通过 06 补测试射验证。
